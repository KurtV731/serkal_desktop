# SerKal 2.5 – unveränderte Originaldateien

Dieser Ordner enthält den vollständigen, unveränderten Originalstand von SerKal 2.5 (Google Apps Script).

## Verbindliche Regel

Die Dateien in diesem Ordner dienen ausschließlich als Referenz für die Desktop-Umsetzung.

- Originaldateien hier nicht bearbeiten, modernisieren oder bereinigen.
- Vor der Übertragung einer vorhandenen Funktion zuerst mit diesen Dateien vergleichen.
- Anpassungen ausschließlich in den eigentlichen Desktop-Quelldateien vornehmen.
- Fehlende Originaldateien vollständig ergänzen, sobald sie vorliegen.

Vorgesehener Inhalt sind insbesondere `ui.html`, `code.gs`, `appsscript.json` und sämtliche zugehörigen `serkal_modul*.gs`-Dateien.
